# Personal Portfolio — Aditya Khiswanda

Website perkenalan sederhana milik mahasiswa Teknik Komputer yang sedang mempelajari pengembangan web dan GitHub.

## Isi repository

- `index.html`: halaman perkenalan, tujuan belajar, dan kontak.
- `README.md`: penjelasan proyek dan cara membukanya.

## Teknologi dan status

Halaman saat ini menggunakan HTML dasar. HTML, CSS, JavaScript, dan GitHub dicantumkan sebagai topik pembelajaran, bukan klaim keahlian profesional. Proyek masih berada pada tahap awal dan belum menampilkan daftar proyek lengkap.

## Cara melihat

Unduh repository, lalu buka `index.html` melalui browser. Tidak memerlukan database atau pemasangan dependensi.

## Rencana pengembangan

- Menambahkan tata letak dan desain responsif.
- Menampilkan proyek yang sudah didokumentasikan dan dipahami.
- Memperbarui deskripsi kemampuan sesuai perkembangan belajar.
- Memastikan kontak yang ditampilkan memang ditujukan untuk publik.

Repository ini tidak menyertakan layanan backend atau aplikasi arsip. Tidak ada alamat deployment yang diklaim tersedia.
